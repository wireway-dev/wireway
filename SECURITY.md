# Security

Wireway sees the traffic you point at it, so a security problem in it matters. Thanks for taking the time to report one.

## Reporting a problem

Write to [support@wireway.dev](mailto:support@wireway.dev) with "Security" in the subject, rather than opening an issue.
Say which version you run (**Wireway > About Wireway**), what you found and how to make it happen. Leave out real traffic:
a made-up host such as `api.example.com` shows the problem just as well.

You'll get a reply, and the fix ships as a Wireway update. Credit in the release notes is yours if you'd like it.

## Versions

Fixes go into the latest version. Wireway updates itself, so keeping automatic checks on (**Settings > General**) is
all it takes to get them.

## Worth reporting

For example:

- another app, device or person on your network reading or changing traffic through Wireway
- Wireway's certificate authority key leaving your Mac
- the local API or the MCP server answering a machine it shouldn't
- an update or a license check that could be tampered with
